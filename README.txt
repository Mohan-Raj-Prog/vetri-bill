VETRI TRAVELS - OFFLINE BILL APP (works on Android / iPhone / PC)
=================================================================
No server, no monthly cost. Put these files on any FREE static host ONCE.
After the first open, the app is saved on the phone and works with NO internet.

STEP 1 - Put it online (free, 2 minutes). Pick one:
  A) Netlify Drop:  open https://app.netlify.com/drop  -> drag this whole folder in.
     You get a link like https://something.netlify.app
  B) GitHub Pages:  create a repo, upload these files, Settings -> Pages -> Deploy from branch (main).
     Link: https://yourname.github.io/reponame/

STEP 2 - On the friend's phone (Chrome):
  1. Open the link (internet needed only this one time).
  2. Menu (3 dots) -> "Add to Home screen" / "Install app".
  3. Open it from the home screen. Turn internet off and check - it still works.

DAILY USE
  - New Bill tab: fill, tap "Save & PDF" -> Share / WhatsApp or Download.
  - History tab: search, Edit, re-share PDF, delete.
  - Settings tab: change business name / address / mobile / logo, and take BACKUPS.

IMPORTANT
  - Bills are stored on the phone only. Use Settings -> "Backup bills" regularly
    (and before changing phone or clearing Chrome data). Restore brings them back.
  - Updating the app later: upload the new files again and change CACHE name in sw.js
    (vetri-bill-v1 -> vetri-bill-v2) so phones pick up the update.
  - Opening index.html straight from the file manager will not install/offline-cache
    (browsers need https). Use the link from Step 1.
